# General

## Use pnpm, not npm
This project uses pnpm (pinned via the `packageManager` field in package.json). Run `pnpm install`, `pnpm run dev`, `pnpm run build`. Do not run npm — it creates a competing package-lock.json, which was removed on purpose. `composer setup` and `composer ci:check` both shell out to pnpm.

Note that CLAUDE.md/AGENTS.md are regenerated by `boost:update` and may reappear mentioning npm; this rule is the source of truth.

## Tests run on Postgres, not SQLite
The app and the test suite both run on Postgres (local DBngin: `elmienda`, tests: `elmienda_test`). Create the test database before running tests.

Do not switch tests back to SQLite in-memory for speed. SQLite hid a real bug: `like` is case-insensitive there but case-sensitive on Postgres, so product search silently matched nothing. Use `whereLike(..., caseSensitive: false)` rather than a raw `like` for user-facing search.
